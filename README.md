# DESBET — site da campanha

Site responsivo em HTML, CSS e JavaScript, preparado para publicação gratuita no Vercel.

## Como testar
Abra `index.html` no navegador. Para uma experiência local mais próxima da publicação, use uma extensão de servidor local ou rode `npx serve .` na pasta do projeto.

## Publicar no Vercel
1. Crie uma conta no GitHub e um repositório novo.
2. Envie todos os arquivos e a pasta `public`.
3. Entre em https://vercel.com/ e importe o repositório.
4. Como é um site estático, não precisa configurar framework nem comando de build. Deixe a pasta raiz como padrão e publique.
5. O Vercel fornece um endereço `*.vercel.app`.

## Personalizar
- A logo usada em `public/desbet-logo.jpg` foi recortada da imagem de identidade visual enviada para a conversa.
- Os links do Instagram estão no `index.html`.
- O checklist é interativo e não salva nem envia respostas.
- Fontes Anton e Roboto são carregadas do Google Fonts; se não houver internet, entram fontes alternativas.
- A arte principal usa elementos gráficos CSS, não uma imagem de tigre inventada.

## Observação
O projeto foi feito como site informativo de campanha, sem login, rastreamento, banco de dados ou coleta de dados pessoais.
